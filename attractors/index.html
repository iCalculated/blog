strange attractors

— a field guide to chaos
Dynamical systems that settle into aperiodic trajectories — bounded but never repeating. Each point is determined by the last, yet the whole pattern remains unpredictable. These are the shapes that chaos makes when it finds balance.

lorenz

σ=10, ρ=28, β=8/3
The butterfly. Two wings folding into each other, a trajectory that never crosses itself. Discovered in 1963 while modeling atmospheric convection — the first hint that weather might be fundamentally unpredictable.
dx/dt = σ(y - x)
dy/dt = x(ρ - z) - y
dz/dt = xy - βz

aizawa

a=0.95, b=0.7, c=0.6, d=3.5, e=0.25, f=0.1
A path with a hole through it. More parameters mean more knobs to turn, more ways for the system to surprise you. The trajectory twists through itself in ways the Lorenz never does.
dx/dt = (z - b)x - dy
dy/dt = dx + (z - b)y
dz/dt = c + az - z³/3 - (x² + y²)(1 + ez) + fz x³

halvorsen

a=1.89
Three-fold rotational symmetry. Spin it 120° and it looks the same. The simplest of the lot — just one parameter — but the structure it traces is anything but simple.
dx/dt = -ax - 4y - 4z - y²
dy/dt = -ay - 4z - 4x - z²
dz/dt = -az - 4x - 4y - x²

thomas

b=0.208186
Cyclically symmetric. The equations rotate through x, y, z like a round. A single parameter controls the whole dance — tune it and the attractor collapses or explodes.
dx/dt = sin(y) - bx
dy/dt = sin(z) - by
dz/dt = sin(x) - bz
